# Synthetic Data Training

The goal of this project is to increase the performance of instance segmentation of neurons on MCFO images.

# Datasets
We have two datasets we are interested as of this experiment:
- fisbe/completely: This dataset contains real MCFO images, with hand labeled instace masks. 
- fisbe/1k_v1_u8: This dataset contains synthetic MCFO images, generated by a different user
